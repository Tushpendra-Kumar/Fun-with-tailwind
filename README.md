## 📌 Overview

A playground and component laboratory dedicated to exploring the power of **Tailwind CSS**. Demonstrates utility-first styling techniques, gradient overlays, responsive flex grids, and component reusability.

---

## ✨ Key Features

- **Utility-First UI Cards:** Modern glassmorphic and gradient cards styled purely through utility classes.
- **Responsive Grid Experiments:** Dynamic multi-column responsive systems adjusting across sm, md, lg, and xl breakpoints.
- **Custom Configuration:** Tailored `tailwind.config.js` with extended color palettes and theme spacing.
- **Micro-Interactions:** State modifiers including `hover:`, `focus:`, and `active:` transitions.

---

## 💻 Tech Stack & Architecture

- **CSS Framework:** Tailwind CSS v3+, PostCSS
- **Tooling:** Node.js, npm scripts

---

## 🚀 Getting Started

### Prerequisites
Node.js installed.

### Installation & Setup
```bash
# 1. Clone this repository
git clone https://github.com/Tushpendra-Kumar/Fun-with-tailwind.git

# 2. Navigate into project directory
cd Fun-with-tailwind

# 3. Install dependencies
npm install

# 4. Build Tailwind CSS
npm run build
```
